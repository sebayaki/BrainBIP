    The same inputs. The same result.

    BrainBIP derives an English BIP39 phrase using the fixed brainbip-v1 profile. The profile uses Argon2id with 256 MiB of memory, 3 passes and 1 lane, plus PBKDF2-SHA256 with 1,048,576 iterations. The additional BIP39 passphrase is empty.

    Inputs use Unicode NFKC normalization. Passphrase spaces and case are preserved; email whitespace at the ends is removed, and its case is preserved. The profile and each address’s derivation path matter for recovery.

    Offline is a complete edition.

    The downloadable HTML contains the app and its cryptographic code. It can run without a server or a network connection. No input is saved to browser storage.

    Strength feedback estimates guessability. It does not establish the entropy of something you chose, and a twelve-word output does not prove 128 bits of input strength. Zcash addresses here are transparent and provide no shielded privacy.
