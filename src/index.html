      THE DETAILS

      Know what you are generating.

      A little context for a reproducible wallet.

      Inputs & normalization+

      The same passphrase, email, and derivation profile reproduce the same wallet. Both inputs use Unicode NFKC normalization. Passphrase spaces and letter case are preserved. Email whitespace at the ends is removed; its letter case is preserved.

      The email is optional. If you use one, you will need that same email to recover. The Private switch changes the estimate only; it never changes the recovery phrase or addresses.

      Strength estimates & private email+

      Estimated bits describe modelled guesswork, not measured entropy. Dictionary words, patterns, personal information, and non-English inputs can behave differently from the model. The display is capped at 128; this is not a security guarantee.

      By default, an email is treated as a public salt and receives zero estimated secret strength. Turning on Private assumes its name is unknown and independent of the passphrase. The app cannot verify either assumption.

      Common words and patterns are easier to guess. This local estimate is not a security guarantee.

      Email contributes 0 estimated bits by default.

      Offline use & security+

      BrainBIP is experimental and has not received an independent security audit. Memory-hard derivation raises the cost of guessing; it cannot create entropy in a predictable passphrase. Anyone who reproduces your inputs can reproduce the wallet.

      The offline edition is a complete HTML file. Save it, then open it locally without a server or internet connection. Inputs are not saved to browser storage or sent over the network.

      Clear & reset discards the app’s inputs and results. It does not clear the system clipboard, and JavaScript cannot guarantee complete memory erasure. Inspect and verify the offline build before entering sensitive inputs.

      Networks & recovery paths+

      The English BIP39 phrase uses an empty additional BIP39 passphrase. Your original BrainBIP passphrase is not the extra passphrase that another wallet may request. Address discovery and import support vary between wallets.

      Ledger mapping · primary + 19 subaddresses

      Bitcoin uses native SegWit. Zcash uses transparent P2PKH addresses, with no shielded privacy. Monero uses the Ledger BIP39 mapping and its own subaddress derivation. A 25-word native export is available in the Monero tab; it restores Monero only, and most Monero wallets cannot import the original twelve BIP39 words.

      BrainBIP displays receiving addresses; it does not query balances or sign transactions.

      Derivation profile · brainbip-v1+

      The fixed profile combines Argon2id with PBKDF2-SHA256 before generating twelve BIP39 words. Argon2id uses 256 MiB of memory, 3 passes, and 1 lane; PBKDF2-SHA256 uses 1,048,576 iterations. Parameters are never reduced automatically on slower devices.

      Keep the derivation profile available for recovery. Twelve output words have a 128-bit entropy capacity; they do not prove 128 bits of input strength. The source includes the full derivation specification and public test vectors.
